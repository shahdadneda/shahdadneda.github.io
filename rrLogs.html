Project Setup & Planning

Today I started planning the Rocket Rumble game. I've decided to create a Flappy Bird-style game with a rocket ship theme. The player will control a rocket that must navigate through obstacles in space.

Key features planned:

  • Rocket ship with physics-based movement
  • Randomly generated obstacles
  • Increasing difficulty
  • Score tracking system
  • Cool space visuals and effects

March 20, 2024

Game Concept

After completing my Obstacle Course game, I've been thinking about what to work on next. I've always enjoyed games like Flappy Bird and wanted to create something similar but with my own twist.

I'm thinking of calling it "Rocket Rumble" - a game where you control a small rocket ship navigating through asteroid fields and space debris. Unlike Flappy Bird which only allows upward movement, I want to implement full directional control while maintaining the simplicity that made Flappy Bird so addictive.
